# 4. Target .NET 10 LTS

- Status: Accepted
- Date: 2026-10-16

## Context

The project was first scoped for .NET 8. .NET 8 reaches end of support on 2026-11-10, less than a month
after the project started. .NET 10 is the current LTS release, supported until November 2028.

## Decision

Target `net10.0` with the SDK pinned in `backend/global.json`. Use the APIs that exist since .NET 8
(Identity API Endpoints, `IExceptionHandler`, built-in rate limiting) so the architecture reads the same for
teams still on .NET 8.

## Consequences

- The app runs on a supported runtime for its whole expected lifetime.
- The built-in OpenAPI document generator replaces Swashbuckle, which the templates no longer include
  since .NET 9. Scalar is used as the interactive UI.
